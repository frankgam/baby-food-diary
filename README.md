# 🍼 Baby Food Diary

เว็บแอปบันทึกอาหาร นม การขับถ่าย อาการแพ้ วัคซีน การเจ็บป่วย และนัดหมอของลูกน้อย (อายุ 6 เดือนขึ้นไป) พร้อมเมนูแนะนำตามวัยและค่าโภชนาการโดยประมาณ

## ใช้งาน
เปิด `index.html` ในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร

## ข้อมูลเก็บที่ไหน
ข้อมูลทั้งหมดเก็บใน `localStorage` ของเบราว์เซอร์บนเครื่องผู้ใช้เท่านั้น ไม่มีการส่งขึ้นเซิร์ฟเวอร์

## ข้อควรรู้
แอปนี้เป็นเครื่องมือบันทึกข้อมูล ไม่ใช่การวินิจฉัยโรค ค่าโภชนาการเป็นค่าประมาณ ควรปรึกษากุมารแพทย์
